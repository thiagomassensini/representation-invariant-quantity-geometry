# README Style Rules

- Use GitHub-native MathJax for all mathematical notation.
- Prefer short paragraphs and displayed equations over ASCII formulas.
- Never expose raw Lean implementation detail before the mathematical statement.
- Keep the README as the conceptual front door, not as an internal checkpoint dump.
- Put implementation and audit detail in dedicated documents.
- The repository front page must remain readable to a mathematician who has never used Lean.
